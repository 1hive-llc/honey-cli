# Security policy

To report a vulnerability, open this repository’s **Security** tab and choose
**Report a vulnerability** to send a private GitHub report. If the option is
not available, do not disclose the vulnerability in a public issue or pull
request.

Include the affected version or commit, expected and observed behavior,
impact, and any safe supporting evidence. Use synthetic data, redact
credentials and wallet material, and do not test against live funds or
accounts you do not control.
